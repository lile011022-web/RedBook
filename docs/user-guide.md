# RedBook Compliance Ops 使用说明

RedBook Compliance Ops 是一个小红书内容团队的合规人工运营工作台。它帮助你管理账号、人设、GPT 文案草稿、人工发布记录、创作中心数据录入和 AI 运营建议，但不提供自动登录、自动发布、群控、代理切换、设备伪装、刷赞、刷评、私信自动化等能力。

## 1. 启动前准备

### 后端服务

桌面软件需要连接本机后端 API。默认地址是：

```text
http://127.0.0.1:8010
```

在项目目录启动后端：

```powershell
cd apps/api
python -m uvicorn app.main:app --reload --port 8010
```

确认后端是否正确：

```powershell
Invoke-RestMethod http://127.0.0.1:8010/health
```

正确结果应包含：

```json
{"status":"ok","service":"redbook-api"}
```

如果 `service` 不是 `redbook-api`，说明当前端口被其他项目占用了。建议使用本说明中的 `8010` 端口启动 RedBook 后端。

### 桌面软件

免安装试用版：

```text
apps/desktop/release/win-unpacked/RedBook Compliance Ops.exe
```

安装包：

```text
apps/desktop/release/RedBook Compliance Ops Setup 0.1.0.exe
```

如果 Windows 提示未知发布者，选择“更多信息”再选择“仍要运行”。这是因为当前安装包还没有代码签名证书。

### OpenAI API Key

GPT 文案和 AI 运营建议需要后端能读取 OpenAI API Key。请把新 key 放在本机环境变量或后端配置里，不要在聊天窗口、截图或公开文档里粘贴真实 key。

PowerShell 临时启动方式：

```powershell
$env:OPENAI_API_KEY="你的新 key"
cd apps/api
python -m uvicorn app.main:app --reload --port 8010
```

如果 key 已经放到后台配置，直接启动后端即可。软件不会在前端显示 API Key。

## 2. 注册与登录

1. 打开软件。
2. 后端地址保持 `http://127.0.0.1:8010`。
3. 首次使用选择 `注册`，输入邮箱和密码，点击 `创建账号`。
4. 已注册用户选择 `登录`，点击 `登录`。

默认输入框里的 `operator@example.com` 和 `password123` 只是示例，可以改成你自己的邮箱和密码。

## 3. 推荐使用流程

### Step 1: 账号

创建小红书账号档案。这里记录的是运营档案，不会登录小红书。

填写：

- 账号名称：账号显示名
- 状态：账号状态
- 健康分：用于人工判断风险

## 多账号小红书独立窗口

每个 RedBook 账号都可以打开自己的小红书官方工作台窗口。窗口使用独立持久会话，因此账号 A 和账号 B 的登录状态不会混在一起。

使用方式：

1. 进入 `账号` 页面。
2. 为每个小红书账号创建一个 RedBook 账号档案。
3. 点击某个账号卡片上的 `打开小红书工作台`。
4. 在打开的小红书官方页面中手动登录。
5. 关闭窗口后，下次从同一个账号打开，会继续使用该账号的本地登录态。

如果小红书官方要求重新登录，需要按官方页面提示手动登录。RedBook 不会自动登录，也不会绕过官方验证。

如果要换号或清掉本地登录态，点击 `清除登录状态`。该操作只影响当前账号，不影响其他账号。

### Step 2: 人设

选择账号后维护人设。

填写：

- 账号定位
- 内容方向
- 语气风格
- 禁用词，用英文逗号分隔
- 发布频率

这些信息会用于草稿合规检查和 AI 草稿提示。

### Step 3: 草稿

创建或生成草稿。

手动草稿：

- 选择账号
- 填写标题、正文、标签、封面文字
- 保存后可审核

AI 草稿：

- 先配置 OpenAI API Key
- 选择账号，确保该账号已维护 `人设`
- 输入 GPT 主题，例如 `合肥直播预告`
- 选择生成数量，支持 1 到 5 版
- 可填写额外要求，例如 `一版偏转化，一版偏种草`
- 生成后默认是 `needs_review`
- 必须人工点击 `通过` 后才能排期

页面里的复制按钮只复制标题、正文、标签或封面文字，不会自动发布。

### Step 4: 排期

只对已审核通过的草稿进行人工排期记录。

注意：

- 未审核 AI 草稿不能排期
- 多账号同一分钟冲突会被阻止
- 这里只是记录排期，不会自动打开平台或自动发布

### Step 5: 运营分析

人工在小红书发布完成后，回到软件记录发布结果。

填写：

- 草稿：对应草稿
- 发布时间：实际发布时间
- 笔记链接：小红书笔记链接

单篇笔记数据：

- 观看量
- 点赞
- 收藏
- 评论
- 记录时间

创作中心数据总览：

根据小红书创作中心页面手动录入数据。当前版本不读取页面、不抓取后台、不要求导出文件。

可录入字段：

- 统计周期：近7日、近30日或自定义
- 开始日期、结束日期
- 曝光数、观看数、点赞数、评论数
- 净涨粉、新增关注、取消关注、主页访客
- 封面点击率、视频完播率
- 收藏数、分享数
- 各指标环比文字，例如 `-40%`
- 备注

保存总览数据后，点击 `根据最新数据生成建议`，AI 会结合当前账号人设、最新录入的数据和近期草稿，给出：

- 问题判断
- 优化建议
- 下一步动作
- 选题方向

这些建议只用于人工判断，不会自动修改账号、自动发布或自动操作小红书。

### Step 6: 合规

查看风险日志，例如：

- 未审核草稿尝试排期
- 多账号同一分钟排期冲突
- 文案相似度或禁用词提醒

## 4. 安装到电脑上

推荐方式：

1. 确认后端可以正常启动，并且 `/health` 返回 `redbook-api`。
2. 双击安装包：

```text
apps/desktop/release/RedBook Compliance Ops Setup 0.1.0.exe
```

3. 按安装向导完成安装。
4. 启动软件后，把后端地址设置为：

```text
http://127.0.0.1:8010
```

5. 注册或登录 RedBook 工作台账号。

如果只是试用，也可以直接运行免安装版本：

```text
apps/desktop/release/win-unpacked/RedBook Compliance Ops.exe
```

## 5. 常见问题

### 报错：Not Found

通常是 API base URL 指向的端口上运行的不是 RedBook 后端。

处理方法：

1. 在 `apps/api` 目录用 `8010` 端口重新启动 RedBook 后端：

```powershell
python -m uvicorn app.main:app --reload --port 8010
```

2. 再打开软件登录。

### 白屏

请使用最新打包版本。旧版本曾经因为本地资源路径问题导致白屏，已修复。

### 登录失败

如果是首次使用，请先切换到 `注册` 创建账号。已经注册过的邮箱再次注册会失败，请切回 `登录`。

### 后端连接不上

检查：

- 后端是否启动
- 后端地址是否是 `http://127.0.0.1:8010`
- 后端地址指向的端口是否被其他程序占用
- `/health` 是否返回 `service: "redbook-api"`

## 6. 合规边界

本软件只支持人工运营辅助：

- 人工创建账号档案
- 人工维护人设
- AI 辅助草稿建议
- 人工审核
- 人工复制内容
- 人工发布后记录结果
- 人工录入数据
- AI 根据人工录入数据给出运营建议

本软件不支持，也不应扩展为：

- 自动登录小红书
- 自动发布
- 群控
- 代理池或 IP 切换
- 设备指纹伪装
- 自动点赞、评论、收藏、私信
- 绕过平台风控
