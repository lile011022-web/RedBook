# RedBook 账号隔离素材库与一键草稿设计

## 目标

恢复并升级 `素材` 功能，让每个账号拥有独立素材库；同时简化 `草稿` 页面，让运营者基于已设置的人设一键生成多篇 GPT 文案，不再填写复杂表单。

## 范围

本版实现：

- 左侧恢复 `素材` 入口。
- 素材必须选择账号后使用，账号 A 只能看到账号 A 的素材。
- 支持本地上传图片、视频和普通文件。
- 上传文件由后端保存到本机项目数据目录，返回可预览/可下载的本地 API URL。
- 图片显示缩略图，视频显示可播放预览，其他文件显示文件卡片。
- 支持 AI 生成图片素材：调用 OpenAI 图片生成能力，生成后保存进当前账号素材库。
- 支持 AI 生成素材创意：封面画面描述、拍摄脚本、短视频分镜、素材清单。
- 草稿页简化为选择账号、生成数量和一个可选补充要求，然后点击 `生成文案`。
- 文案生成必须读取该账号 `人设`，输出多篇待审核草稿。
- 对不满意的文案，用户再次点击生成即可追加新的候选草稿。
- GPT 与图片生成失败时给出清晰中文错误，不显示或记录 API Key。

本版不实现：

- 自动登录小红书。
- 自动发布。
- 自动读取小红书后台。
- 跨账号共用素材。
- 自动生成长视频成片。
- 绕过平台风控、代理、设备伪装、刷赞刷评刷私信。

## 后端设计

### 素材存储

新增本地文件存储目录：

```text
apps/api/data/media/accounts/{account_id}/{asset_id}/{filename}
```

后端只把当前账号素材列给当前请求页面。文件 URL 使用 API 代理输出：

```text
GET /media-assets/{asset_id}/file
```

访问文件时校验素材记录存在。素材记录仍包含 `account_id`，因此客户端不能通过账号 B 的列表拿到账号 A 的素材。

### 上传接口

新增：

```text
POST /accounts/{account_id}/media-assets/upload
```

字段：

- `file`: 本地文件。
- `source`: 默认 `upload`。

服务端：

- 校验账号存在。
- 计算 sha256。
- 保存文件。
- 写入 `MediaAsset`。
- 如果同 sha256 已在其他账号出现，继续写风险日志。

### AI 图片与创意接口

新增：

```text
POST /accounts/{account_id}/media-assets/generate-image
POST /accounts/{account_id}/media-ideas
```

`generate-image`：

- 输入主题和风格要求。
- 调 OpenAI 图片生成。
- 保存图片文件到当前账号素材库。
- 写入 `MediaAsset.source = "ai_image"`。

`media-ideas`：

- 输入素材目标。
- 结合账号人设生成素材创意 JSON。
- 返回封面画面、拍摄脚本、视频分镜、素材清单。

### 数据模型

扩展 `MediaAsset`：

- `source`: `upload` / `ai_image` / `external`
- `file_size`: 文件大小。
- `width`: 可选，图片宽度。
- `height`: 可选，图片高度。

现有旧字段保持兼容。

## 前端设计

### 素材页

页面结构：

- 账号选择器。
- 上传区域：支持拖拽/选择文件，提示支持图片、视频和普通文件。
- AI 素材区：输入主题，生成图片；输入素材目标，生成创意。
- 当前账号素材库网格。

素材卡片：

- 图片：缩略图。
- 视频：视频预览。
- 其他：文件名、类型、大小。
- 标签：本地上传 / AI 生成 / 外链记录。

### 草稿页

保留草稿审核列表，但创建区简化：

- 账号选择。
- 生成数量：1-5。
- 可选补充要求。
- `生成文案` 按钮。

生成逻辑：

- 如果账号没有人设，提示先去 `人设` 设置。
- 点击后调用 `/ai/generate-draft-options`。
- 返回草稿后刷新列表。
- 用户不满意可以再次点击生成，系统追加新的待审核草稿。

## GPT 连通性

交付前必须验证：

- `OPENAI_API_KEY` 是否存在，仅输出 SET/UNSET。
- 当前后端 Python 是否安装 `openai` 包。
- 使用正确工作目录 `apps/api` 启动后端。
- 用测试账号和人设调用 `/ai/generate-draft-options`。
- 成功时确认草稿写入。
- 失败时记录清晰原因，例如缺依赖、模型不可用、key 无效、余额/权限问题或网络问题。

## 验收

- 账号 A 上传素材后，只在账号 A 素材页显示。
- 账号 B 看不到账号 A 素材。
- 图片能预览，视频能显示视频控件。
- AI 图片生成后素材进入当前账号素材库。
- 草稿页只需要选择账号、数量并点击生成。
- GPT 文案生成能真实跑通，失败时有中文错误。
- 后端测试、前端类型检查、生产构建和 Windows 打包通过。
